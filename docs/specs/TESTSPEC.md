## 1. Test Strategy

- **Unit tests (Vitest):** point-to-vector projection/coverage math, boundary-box containment
  check, deviation-angle calculation (M2), segment-completion state transitions.
- **Integration tests (React Testing Library):** Tracing/Letter Selection screen components render
  correct states/visibility per UISPEC; navigation between screens.
- **E2E tests (Playwright):** full core loop — trace every segment of a letter, get feedback, see
  the celebration animation, navigate to another letter — across Chrome and iPadOS Safari (or
  simulated touch viewport).

## 2. Fixtures & Test Data

- `src/data/letterSegments/*.ts` — authored `LetterDefinition` fixtures for in-scope letters,
  including uppercase A-Z and lowercase a-z under `english/capitalLetters` and
  `english/lowercaseLetters`.
- Synthetic trace paths are represented inline in unit/integration tests (same approach used in
  tasks 001 and 002), not as committed `fixtures/tracePaths/*.json` files.
- `src/data/letterSegments/__tests__/letters.test.ts` — fixture invariants for every exported
  letter (alphabet order, non-empty metadata, non-degenerate segments, normalized endpoints).
- `src/data/letterSegments/english/lowercaseLetters/__tests__/letters.test.ts` — lowercase a-z
  invariants: endpoints inside the 1×1.36 lowercase canvas (descenders allowed below y=1),
  non-zero length for open segments, and closed full circles (`start === end`, non-zero radii).
- `src/modules/tracing/__tests__/TracingScreen.alphabet.test.tsx` — smoke test that navigates
  through the full `letters` list and asserts segment guide markers render for every letter.
- `src/modules/tracing/__tests__/characterization.test.ts` — golden-master characterization that
  verifies every authored tracable segment can complete against its ideal path and snapshots
  coverage/containment metrics.
- `src/modules/tracing/__tests__/forgiveness.test.ts` — task 013 forgiveness coverage (T-036 to
  T-039): wider corridor, enlarged start region, start/end marker overlap invariant, curve
  deviation persistence, scripted "wobbly child" traces of C/G/O/U (upper and lower case), and
  resume after lift through `useSegmentTrace`.

## 4. Dry-Run Protocol

Before marking a milestone done, a human tester manually:

1. Loads the app fresh on a touchscreen device.
2. Traces at least 3 letters fully, including at least one deliberate boundary-box exit and one
   deliberate <80%-coverage finger-up.
3. Confirms feedback is immediate and understandable to a non-reading child.
4. Repeats on desktop with mouse input.
5. For M2: tests the deviation cancel-on-threshold behavior (a deliberate steep drift inside the
   box resets the segment); the start-region rule (a tap on the middle of the line does not start
   tracing); the end-region auto-complete rule (dragging into the end marker completes the segment
   without a finger-up); and the exit-after-80%-still-resets rule.
6. For M3 (shadow feature):
   - Confirms Easy mode shows a persistent faint ghost outline of every letter while tracing.
   - Confirms Hard mode shows the shadow alone for approximately 2 seconds on letter open.
   - Confirms Hard mode pointer events are blocked during the shadow preview.
   - Confirms after the preview ends, the segment guide appears and tracing begins normally.

- Confirms Hard mode launches the same authored fixture as Easy mode (difficulty differs only by preview behavior).

7. _(previous step 6)_ For M3 Train: opens Letter Selection from the Run-only Train button, verifies lowercase default and Hard mode off, selects a practice letter, and tests Train Menu discard, Next wraparound, Hard mode preview and Home's return to Run at lowercase "a".
8. For Task 009 (Lowercase + case toggle):

- Confirms Train Letter Selection case toggle starts on Lowercase and can be switched to Uppercase.
- Confirms lowercase tiles (a-z) are visible in lowercase mode and launch lowercase tracing.
- Confirms switching back to Uppercase restores uppercase tiles (A-Z).
- Confirms all four combinations (Easy/Uppercase, Easy/Lowercase, Hard/Uppercase, Hard/Lowercase) launch expected tracing behavior.

9. For Task 008 (Helplines) and Task 014:

- Confirms Run opens on lowercase "a", has only the icon-only Train button, uses Easy mode, and always shows Helplines without a toggle.
- Confirms letters advance only after completion, the completed letter remains drawn through the animation, and the next letter opens one second after the animation ends.
- Confirms completing z shows a button-free "You did it!" screen for 3 seconds, then starts uppercase A; completing Z shows it again, then loops to lowercase a.
- Confirms Train drops Run, opens lowercase Letter Selection, and Home restarts Run at lowercase a.
- Confirms a Helplines toggle is visible in Train tracing in both Easy and Hard mode and starts off on every letter open.
- Confirms enabling Helplines shows three horizontal guides at y=0.14, y=0.50 (dashed), and y=0.86.
- For lowercase letters, confirms a fourth dashed descender guide appears at y=1.22.
- Confirms guides span almost side-to-side with small left/right insets.
- Confirms disabling Helplines hides all three guides.
- Confirms helpline toggling does not change completion/reset behavior.

10. _(previous step 9)_ For M4: installs the packaged container build and repeats steps 1–4 inside the Curious Reader
    container itself.
11. For Task 013 (forgiveness & direction guidance), on the target tablet:

- Confirms a child hits the start dot first try on 10 letters, that it pulses while waiting and is still under the finger.
- Confirms the corridor band is light and does not hide the shadow or the guide.
- Confirms the demo dot glides smoothly on a line (A), a curve (C) and a polyline (U), replays after a wrong press, and stops once tracing starts.
- Confirms the guide dashes flow from start to end.
- Confirms a child can finish C, G, O, U and c, g, o, u; a wobbly trace is accepted; tracing the wrong way still resets.
- Confirms lifting mid-curve keeps the green progress and shows a resume dot; pressing it continues; pressing the start dot restarts.
- Confirms Hard mode shows the band and demo after the 2 s preview.
- Confirms OS reduced motion stops the pulse and dashes and hides the demo dot.

12. For Task 014, signs off the Run/Train flow and confirms all five Task 014 physical-device checklist items passed (2026-10-27 human verification).
