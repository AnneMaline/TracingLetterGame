# Draft tasks

Task plans proposed by the AI Planner, awaiting human approval/prioritization. Not yet started.

Naming convention: `NNN-short-slug.md` (e.g. `001-letter-select-screen.md`), numbered sequentially
across draft + active + done combined so numbers never collide as a task moves through
`../active/` and finally `../done/`.

Each task file should state: what & why, what "done" looks like (tying back to specific DEVSPEC
module / UISPEC screen / TESTSPEC case IDs), what's out of scope, and the implementation steps.
